# Security Policy

## Scope

This repository is three small SSH config files, an example file and setup instructions. It contains no service and no library. In scope:

- A setting that weakens authentication or key handling without the reference saying so
- Any real key, host entry or personal detail committed by mistake
- Setup instructions that would leave insecure file permissions behind
- A setup instruction that would leave insecure file permissions behind

## Out of scope

- A vulnerability in OpenSSH itself, report that upstream

## Reporting a vulnerability

> [!IMPORTANT]
> Report privately, not in a public issue. Email contact@isaacadjei.me with details and
> reproduction steps. Expect an acknowledgement within a few days.
